# Git 学习任务清单

这是一个不依赖第三方库的静态网页小项目，用来配合手动练习 Git 的基础操作。

## 项目文件

- `index.html`：页面结构，负责标题、进度区域和任务列表容器。
- `style.css`：页面样式，负责布局、颜色、按钮和响应式显示。
- `app.js`：页面交互逻辑，负责渲染任务、标记完成和更新已完成数量。
- `README.md`：项目说明，帮助你了解这个练习项目的用途。

## 如何使用

1. 直接在浏览器中打开 `index.html`。
2. 查看任务列表。
3. 点击“标记完成”按钮，观察任务状态和完成数量变化。

## 学习目标

- 理解一个最小前端项目的文件结构。
- 用这个项目作为 Git 学习练习素材。
- 在后续步骤中手动完成 Git 初始化、查看状态、暂存和提交等操作。
